# EvoluFísico Alpha — 0.1.0 Beta

## Incluído

- Aplicativo EvoluFísico2 completo como base, com modo **Pro** preservado.
- Novo modo **Moderno** configurável em **Configurações → Personalização**.
- Dashboard com widgets instalados inicialmente para os módulos originais.
- Biblioteca para instalar/remover widgets, redimensionar, reorganizar e criar pilhas.
- Nenhuma pilha pré-instalada; a função de empilhamento continua disponível.
- Navegação Moderna travada em **Estendido**, sem barra lateral.
- Dock de nove módulos originais, visível somente após a conclusão da tela de abertura.
- Suporte aos temas claro e escuro do aplicativo.

## Notas

Base integrada de homologação: EvoluFísico2 **1.0.30 Pré-Beta**. Não corresponde necessariamente à última revisão estável. Sem migração ou publicação automática; versão separada para testes. Recomenda-se não inserir dados sensíveis nesta fase.

## Abrir

Abra `index.html` no navegador. Para maior compatibilidade: `python -m http.server 8000` e acesse `http://localhost:8000`.
